# 1010 PHYSICS — 1010! с настоящей физикой

Та же головоломка «1010!», но все фигуры — физические тела: падают, сталкиваются,
цепляются друг за друга и дожимаются в уже занятые места. Поле по-прежнему
сгорает по полностью заполненным линиям — но теперь порядок приходится
возвращать laws physics… то есть законам физики.

> 🎮 **Играть онлайн:** <https://1010-game-physics.vercel.app/>
> Игра входит в хаб браузерных игр **GOSU**.

## Что внутри

- **Реальная физика** на Matter.js: фигуры летят, кувыркаются и занимают клетки
  не по сетке, а как повезёт. Линии всё так же сгорают, а вот выкладывать их —
  уже борьба с энтропией.
- **16 случайных событий** каждые ~20 секунд: гравитация тянет вбок, блоки
  замерзают (ледяная гладкость) или каменеют, по полю гуляют вихри, бомбарды,
  масляные лужи, рост, спящий «сюрприз» и прочий хаос.
- **10 специальных клеток** в фигурах: бомба, лужа, магнит, лутбокс, огонь,
  разряд, цепная реакция, ледяная и каменная бомбы и др.
- **4 вида оружия** (точечный выстрел, дробовик, плазменный луч, пушка) —
  боезапас зарабатывается на поле, действует окно в 25 секунд. Клавиши 1–4.
- **8 тем оформления** (standard / day / night / mono / neon / green / red / acid)
  и **7 языков интерфейса** (русский, English, 中文, Français, Español, Italiano,
  Башҡортса).
- **Раунды и рекорды**, мягкая «гибель» с показом причины, автосохранение настроек,
  поддержка мыши, тача и гостевого превью фигуры под курсором.

## Технологии

| Слой | Что |
|---|---|
| Рендер | `<canvas>` + CSS-хром, React 19 |
| Физика | Matter.js |
| Сборка | Vite 7 + Tailwind CSS 4 + `vite-plugin-singlefile` |
| Иконки | lucide-react |

`postbuild`-скрипт `scripts/file-safe.mjs` превращает собранный `dist/index.html`
в файл, который открывается двойным кликом прямо с диска (`file://`): модульные
`<script>` переписываются в классические и переносятся в конец `<body>`.

## Запуск

```bash
pnpm install
pnpm run dev        # Vite dev-сервер (по умолчанию http://localhost:5173)
```

## Сборка и деплой

```bash
pnpm run build      # → dist/index.html (весь бандл в одном файле)
pnpm run preview
```

Собранный `dist/` — это статический сайт: залейте его на Vercel / Netlify /
GitHub Pages или просто откройте `dist/index.html` двойным кликом.

## Проверки и производительность

```bash
pnpm run typecheck  # строгая проверка TypeScript
pnpm test           # регрессионные тесты оптимизаций
pnpm run bench      # воспроизводимый CPU-микробенчмарк (Node.js, без GPU)
```

Оптимизации не меняют частоту физики (60 Гц), параметры решателя, разрешение
canvas или количество эффектов:

- Пространственный индекс ускоряет проверку третьего слоя и поиск свободного
  места. Индекс строится заново для каждого прохода, чтобы не использовать
  устаревшие координаты после движения или разрушения блоков.
- Проверка линий использует битовые маски и переиспользуемые буферы.
- Resize с неизменным масштабом сохраняет спрайты и сетку; блоки нестандартных
  цветов тоже кэшируются, а не рисуют тени заново каждый кадр.
- Перемещение предпросмотра фигуры не вызывает перерисовку всего React HUD.
- Пустые проверки выгорания не вычисляют мировые координаты всех клеток.

Локальный замер на поле из 79 клеток (Node 24, медиана 7 серий):

| Операция | До, мс | После, мс |
|---|---:|---:|
| Проверка наложения | 0.0915 | 0.0220 |
| Поиск свободного места | 0.1396 | 0.0277 |
| Проверка линий | 0.0227 | 0.0080 |

Это замеры отдельных операций, не обещание роста FPS во столько же раз.
Тесты сверяют индекс и битовые маски с исходными алгоритмами, включая границы,
пересечения линий и исключение перетаскиваемых/неподвижных фигур.

## Структура

```
src/
  main.tsx      — точка входа
  App.tsx       — UI, HUD, оверлеи, ввод
  game.ts       — физика и игровая логика (Matter.js, события, оружие, спецклетки)
  spatial.ts    — переиспользуемый пространственный индекс для проверки наложений
  i18n.ts       — строки интерфейса на 7 языках
  index.css     — Tailwind 4 + темы (data-theme)
scripts/
  file-safe.mjs — пост-сборка: совместимость dist с file://
tests/
  performance.test.mjs — проверки сохранения поведения и кэшей
  benchmark.mjs       — локальные замеры горячих операций
```
